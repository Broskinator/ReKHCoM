# Generated HUD label prompts

Built-in imagegen tool; original game screenshots supplied as shape references.
Transparent background requested for every generation/edit. PNG resources are
kept non-destructively as versioned files; runtime crops alpha padding and fits
the bright face to the native glyph bounds. The rejected noisy alphabet atlas
is not included in the pack.

## LP initial generation (label-lp-v1.png)

Create ONE isolated HD game HUD label reading exactly LP, based on the letters
in the TOP RIGHT panel of this reference screenshot. Retain chunky compact
proportions and spacing. Redraw all contours as clean continuous geometric
lines and smooth antialiased tiny chamfers: no staircase pixels. Bright green
thick faces, pale green thin top bevel, dark green subtle lower-right shadow
preserving the original's relief. No glow, no grain, no speckles, no scattered
alpha dots, no blur. The letters LP only, no frame, no health bar, no panel,
no extra text. Transparent counters inside letters, fully transparent exterior
with generous padding, real alpha. This is a clean modern 2D remaster UI asset,
readable at small sizes.
