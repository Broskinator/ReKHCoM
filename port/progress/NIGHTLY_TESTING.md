# ReKHCoM v1.9.3 Nightly 3 — 2026-10-18

Public test build / prerelease. Stable remains v1.9.2.

- Incorporates Claude's save-crystal fixes: slot summary, correct destination
  flag/last saved slot, launcher persistence and Experimental setting.
- Android and Web: Options > Experimental > Hide touch controls. The choice
  persists; hiding clears held touch inputs. A small options button remains,
  and navigation buttons are available while Options is open for recovery.
- Contains the wider 057/061/074 scene profiles and the earlier Guard Armor
  improvement. Leon 004 is unchanged; the other scenes remain improvable.
- Includes the integrated PS5 port from PR #15 as alpha, built for this release.
- Windows, Android, Web, Linux and PS5 checks are recorded in the release
  report. Build success is not proof of performance on Odin 2 or PS5 hardware.

No cartridges, SRAM, quickstates or personal settings are distributed.
Darkside WIP is excluded. No new art extensions were started for this release.
