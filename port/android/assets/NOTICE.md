# Controles táctiles de ReKHCoM

Arte vectorial propio preparado para este proyecto: `roll.svg` y `stock.svg`.
Se aplica el mismo color y opacidad del overlay al dibujarlo; los SVG conservan
el fondo transparente y no contienen el marco del botón.

La silueta representa a Sora rodando y el segundo símbolo muestra naipes
apilados. No son sprites extraídos de una ROM. Sora y Kingdom Hearts pertenecen
a sus titulares; este proyecto es un port no oficial.

Distribución inspirada funcionalmente en la disposición GBA y el overlay
landscape de RetroArch. No se copian sus texturas ni código. Los SVG están
bajo la licencia del repositorio. Este es arte de prototipo pendiente de
revisión en un móvil real; no implica una versión Android disponible.
